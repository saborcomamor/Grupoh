# Grupo Haymour — protótipo visual

Projeto Next.js mobile-first com GSAP ScrollTrigger, hero com parallax e galeria editorial em perspectiva.

## Executar

```bash
npm install
npm run dev
```

**Atenção:** as fotografias são ilustrativas, de terceiros, e não representam obras da Haymour. Substituir por mídias autorizadas antes de qualquer publicação pública. Contato, painel, Supabase e experiência WebGL ainda não implementados.
